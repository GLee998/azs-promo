Как участвовать в акции «Караван Coca‑Cola»

  1. Купите комбоКомбо «Караван Coca‑Cola»: 2 френч-дога и 2 бутылки Coca‑Cola 0,5 л.
  2. Зарегистрируйте чекОтсканируйте QR-код на кассе и зарегистрируйте чек по номеру телефона. Один чек можно зарегистрировать только один раз.
  3. Получите брендированную машинку Coca‑ColaМашинка выдаётся один раз за всю акцию на один номер телефона.
  4. Участвуйте в розыгрышеОдин номер телефона даёт один шанс выиграть поездку на новогоднем караване. Всего разыгрывается 8 поездок, по одной на каждого победителя.
