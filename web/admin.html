Реестр заявок

Вход для маркетинга

Первый вход после простоя может занять до минуты: бесплатный сервер просыпается.

Сверка с выгрузками кассы

CSV с колонками fn;fd;fp, для продаж ещё qty — число комбо в чеке. Продажи отмечают «покупка сверена», выдачи отмечают «игрушка выдана», возвраты снимают заявку с розыгрыша.

Порядок проверки

  • Покупка была: сверяем фискальные данные чека с выгрузкой продаж (позиция «Комбо Coca-Cola»).
  • Чек не отправлен повторно: совпадение ФН + ФД + ФМ помечается как дубликат, даже если фото обрезали или пересняли. Допустить один чек дважды система не даст. В спорных случаях просим оригинал или электронный чек.
  • Игрушка выдана: сверяем чек с отметкой о выдаче на кассе.
  • Покупку не вернули: перед розыгрышем загружаем выгрузку возвратов, такие заявки снимаются автоматически.
  • Номера участников выдаются при допуске, по одному на каждое комбо в чеке.
